**EdgeLedger Financial Website**

This is a landing page for a fictional financial services company called EdgeLedger. I built this to practice creating a professional business layout that works well on both desktop and mobile devices.

**Live Site**

You can see the project live here: rogerslutamaguzi.github.io/edgeledger

**About the project**

The main goal of this site was to handle a lot of different sections—like the About, Cases, and Team areas—while keeping the design clean and easy to navigate.
I used a bit of JavaScript to make the navigation bar more functional. When you scroll down more than 100 pixels, the navbar changes its look to stay readable against the content, which gives the site a more polished feel.
Technical Details
HTML/CSS: I used custom CSS with Flexbox for the grid layouts and the side-by-side sections.
Navigation: The sticky header is controlled by a scroll listener in the script at the bottom of the HTML file.
Icons: I used Font Awesome for the social media and service icons.
Images: All project images are stored in the /img/ directory.

**How to Run This Locally**

If you want to run this on your own machine:
Clone the repository.
Open the index.html file in any modern web browser.
Make sure the /css/ and /img/ folders are in the same directory as the HTML file so the styles and pictures load correctly.
